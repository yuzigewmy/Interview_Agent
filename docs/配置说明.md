# 配置说明

## 1. 演示模式

首次启动默认开启演示模式，不需要任何密钥：

- 文本问题可以走本地知识库检索。
- 回答由本地演示生成器组织，用于验证界面和 RAG 流程。
- 音频可以采集，但不会上传，也不会产生真实转写。

需要真实语音转写和模型回答时，在右上角“设置”中填写凭据并关闭演示模式。

## 2. 回答模型

应用支持 OpenAI Chat Completions 兼容接口。设置页可以分别填写：

- 模型提供商：只用于界面显示，例如 `DeepSeek`、`通义千问`、`Ollama`。
- Model Name：服务要求的精确模型标识。
- Base URL：API 根地址或以 `/chat/completions` 结尾的完整地址。
- API Key：远程服务通常必填；无需鉴权的本机服务可留空。
- 最大输出 Token：范围 64–8192。

远程 Base URL 必须使用 HTTPS。Ollama、LM Studio 等运行在本机的服务可以使用 `http://localhost`、`http://127.0.0.1` 或 `http://[::1]`。应用会在根地址后追加 `/chat/completions`，并保持 SSE 流式输出。完全不同于 OpenAI Chat Completions 的厂商私有协议暂不支持。

当模型提供商以 `DeepSeek` 开头，或 Base URL 使用官方 `api.deepseek.com` 时，应用会自动发送 `thinking: disabled` 和低温度参数，恢复适合面试场景的低首字延迟。[DeepSeek 官方思考模式说明](https://api-docs.deepseek.com/guides/thinking_mode)指出 V4 默认开启思考；若不显式关闭，模型可能先生成应用不展示的推理内容。

设置页不会回显已经保存的密钥：

- 密码框留空且 Base URL 未改变：保留原密钥。
- 更改 Base URL 后密钥框留空：自动清除旧模型密钥，防止把上一家服务的密钥发送到新地址。
- 输入新值：覆盖原密钥。
- 勾选“清除全部云服务凭据”：清空所有 API Key / Token，但保留模型名称与地址。

## 3. 火山引擎实时语音识别

应用使用优化后的双向流式地址：

```text
wss://openspeech.bytedance.com/api/v3/sauc/bigmodel_async
```

支持两种鉴权方式：

- 新控制台：填写“火山 API Key”。
- 旧控制台：同时填写 AppKey 和 AccessKey。

Resource ID 默认是：

```text
volc.seedasr.sauc.duration
```

它对应 2.0 小时版；若你的控制台开通的是 1.0 小时版，可改为：

```text
volc.bigasr.sauc.duration
```

火山引擎当前文档列出了两种资源 ID；接口升级记录也给出了优化版 WebSocket 地址，可参考[官方产品更新](https://www.volcengine.com/docs/6561/162929)。

如果提示鉴权失败，请依次检查：

1. 服务是否已经在火山控制台开通。
2. Resource ID 是否与购买/开通的版本一致。
3. 新旧凭据是否混填。
4. 系统时间是否正确、网络是否允许 WebSocket。

## 4. 音频来源

- “系统输出”：通过 WASAPI Loopback 获取耳机/扬声器正在播放的会议声音。
- “麦克风”：获取选中录音设备，适合面试官声音从外部设备播放的情况。

应用统一转成 16 kHz、16-bit、单声道 PCM。面试官提问时开始采集，候选人作答前停止采集，以减少冲突。

全局热键是 `F8`。如果被其他软件占用，界面会显示提示，仍可使用按钮。

插入蓝牙耳机、USB 麦克风或虚拟声卡后，点击音频来源右侧的圆形双箭头图标即可重新枚举设备；原设备仍存在时会保持当前选择。

## 5. 桌面悬浮球

在设置页勾选“启用桌面悬浮球”并保存后，悬浮球会立即出现：

- 单击悬浮球：开始或停止问题采集；为了区分双击，会等待 Windows 当前的双击判定时间。全局 `F8` 仍然立即响应。
- 双击悬浮球：恢复并置顶主窗口，不改变当前采集状态。
- 拖动球体：移动位置；拖动右下沿的小型斜线手柄：调整大小。
- 停止采集时显示红色斜线麦克风；采集中显示绿色麦克风；检测到声音时，蓝色波浪高度随音量变化。
- 绿色气泡显示当前转写，白色气泡显示流式回答。每轮只保留这两个气泡，开始下一轮时清除。
- 长答案限制显示高度并自动滚动到最新内容，仍可用鼠标滚轮查看前文。

悬浮球默认直径为 72，允许范围为 56–128。位置和大小随加密设置保存；显示器或 DPI 变化后会自动拉回当前工作区。悬浮球和气泡均不显示任务栏图标，普通操作不会抢占面试窗口焦点。关闭主窗口仍会退出整个程序。

## 6. 面经与 BGE

首次运行会尝试导入桌面的 `面经.docx`。也可以随时点击“导入 DOCX”替换知识库。

发布包内置 BAAI `bge-small-zh-v1.5` 的量化 ONNX 转换文件。应用优先查找：

1. `%LOCALAPPDATA%\InterviewAgent\models\bge-small-zh-v1.5`
2. 程序目录下的 `models\bge-small-zh-v1.5`

如果模型缺失或加载失败，会自动降级到本地字符 n-gram 向量，FTS5 关键词检索仍然可用。安装/修复本地模型后要重新导入 DOCX，使库内向量维度一致。

## 7. 短期记忆与问答导出

- 每次成功完成的回答会作为一轮问答保存在内存中。
- 最近 6 轮、最多约 6,000 字符会辅助模型理解“那它呢”“继续说利用链”等追问。
- 会话最多保留 500 轮，程序退出后立即清除，不写入数据库或设置文件。
- 面试结束后点击“导出记录”，默认文件名是 `<首道纠正后问题>_<yyyyMMdd_HHmmss>.docx`。
- 只有用户确认保存位置后才会生成文件。

## 8. 五秒策略

- 检索先执行，配置的模型服务随后开始流式请求。
- 模型服务在 4.0 秒前产生首个文本时，直接显示云端流。
- 4.0 秒仍无首字时，先显示最相关的本地面经答案。
- 云端后续到达后，界面切换为完整流式回答。
- 单道问题总超时为 30 秒，新问题会取消旧问题。

该机制保证有知识库命中的情况下，5 秒节点前已有可读输出；它不能保证第三方网络服务自身始终可用。
