# 配置说明

## 1. 演示模式

首次启动默认开启演示模式，不需要任何密钥：

- 文本问题可以走本地知识库检索。
- 回答由本地演示生成器组织，用于验证界面和 RAG 流程。
- 音频可以采集，但不会上传，也不会产生真实转写。

需要真实语音转写和模型回答时，在右上角“设置”中填写凭据并关闭演示模式。

## 2. DeepSeek

需要一个 DeepSeek API Key。应用调用：

```text
POST https://api.deepseek.com/chat/completions
model: deepseek-v4-flash
thinking: disabled
stream: true
```

关闭思考模式是为了降低首字延迟。DeepSeek 当前的模型名称和 SSE 终止格式可在[官方 Chat Completion 文档](https://api-docs.deepseek.com/api/create-chat-completion/)查看。

设置页不会回显已经保存的密钥：

- 密码框留空：保留原密钥。
- 输入新值：覆盖原密钥。
- 勾选“清除全部云服务凭据”：清空所有密钥。

## 3. 火山引擎实时语音识别

应用使用优化后的双向流式地址：

```text
wss://openspeech.bytedance.com/api/v3/sauc/bigmodel_async
```

支持两种鉴权方式：

- 新控制台：填写“火山 API Key”。
- 旧控制台：同时填写 AppKey 和 AccessKey。

Resource ID 默认是：

```text
volc.seedasr.sauc.duration
```

它对应 2.0 小时版；若你的控制台开通的是 1.0 小时版，可改为：

```text
volc.bigasr.sauc.duration
```

火山引擎当前文档列出了两种资源 ID；接口升级记录也给出了优化版 WebSocket 地址，可参考[官方产品更新](https://www.volcengine.com/docs/6561/162929)。

如果提示鉴权失败，请依次检查：

1. 服务是否已经在火山控制台开通。
2. Resource ID 是否与购买/开通的版本一致。
3. 新旧凭据是否混填。
4. 系统时间是否正确、网络是否允许 WebSocket。

## 4. 音频来源

- “系统输出”：通过 WASAPI Loopback 获取耳机/扬声器正在播放的会议声音。
- “麦克风”：获取选中录音设备，适合面试官声音从外部设备播放的情况。

应用统一转成 16 kHz、16-bit、单声道 PCM。面试官提问时开始采集，候选人作答前停止采集，以减少冲突。

全局热键是 `F8`。如果被其他软件占用，界面会显示提示，仍可使用按钮。

## 5. 面经与 BGE

首次运行会尝试导入桌面的 `面经.docx`。也可以随时点击“导入 DOCX”替换知识库。

发布包内置 BAAI `bge-small-zh-v1.5` 的量化 ONNX 转换文件。应用优先查找：

1. `%LOCALAPPDATA%\InterviewAgent\models\bge-small-zh-v1.5`
2. 程序目录下的 `models\bge-small-zh-v1.5`

如果模型缺失或加载失败，会自动降级到本地字符 n-gram 向量，FTS5 关键词检索仍然可用。安装/修复本地模型后要重新导入 DOCX，使库内向量维度一致。

## 6. 五秒策略

- 检索先执行，DeepSeek 随后开始流式请求。
- DeepSeek 在 4.5 秒前产生首个文本时，直接显示云端流。
- 4.5 秒仍无首字时，先显示最相关的本地面经答案。
- 云端后续到达后，界面切换为完整流式回答。
- 单道问题总超时为 30 秒，新问题会取消旧问题。

该机制保证有知识库命中的情况下，5 秒节点前已有可读输出；它不能保证第三方网络服务自身始终可用。
