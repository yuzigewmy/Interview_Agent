## 五秒目标

自动化测试证明：

- 云端首字先到时不显示本地兜底。
- 云端无首字时在配置的 4.5 秒边界显示知识库答案。
- 总请求 30 秒超时，新问题取消旧问题。

未使用真实模型服务 API Key 测量公网首字时间。即使第三方服务变慢，只要知识库有命中，4.5 秒本地路径仍会先输出；网络完全不可用时则保留本地答案并显示安全错误。
