# Interview Agent v0.1 测试报告

日期：2026-07-23  
环境：Windows x64、.NET SDK 8.0.423、Release 配置

第一版通过本地发布门禁，可交付试用。核心文本/RAG、五秒兜底、协议解析、密钥存储和真实 BGE 推理已经自动化验证。DeepSeek 与火山引擎的真实线上联调尚未执行，因为当前没有用户云服务凭据。

- 平均检索耗时：21.7 ms。

这说明当前 241 块规模无需独立向量数据库；SQLite + FTS5 + BGE 的延迟远低于 5 秒总预算。

## 安全检查

```powershell
dotnet list InterviewAgent.sln package --vulnerable --include-transitive
```

结果：所有项目均为 0 个已知易受攻击包。

另外确认：

- 密钥只进入 DPAPI `CurrentUser` 密文。
- 设置页不回显已保存凭据。
- 日志字段采用白名单，不记录问题、答案、知识正文、音频或密钥。
- DOCX 与 WebSocket 消息有大小上限。
- FTS/SQLite 查询参数化。
- BGE 模型和词表按固定提交下载并验证 SHA-256。

## 五秒目标

自动化测试证明：

- 云端首字先到时不显示本地兜底。
- 云端无首字时在配置的 4.5 秒边界显示知识库答案。
- 总请求 30 秒超时，新问题取消旧问题。

未使用真实 DeepSeek Key 测量公网首字时间。即使第三方服务变慢，只要知识库有命中，4.5 秒本地路径仍会先输出；网络完全不可用时则保留本地答案并显示安全错误。
